ΑΛΛΑΓΕΣ ΣΤΟ ΑΡΧΕΙΟ .csproj
==========================
Άνοιξε το .csproj του έργου (δεξί κλικ στο έργο στο Solution Explorer, "Edit Project File") και φρόντισε να ισχύουν τα παρακάτω.

1) Στο <PropertyGroup> πρόσθεσε ή άλλαξε αυτές τις γραμμές:

    <TargetFramework>net10.0-windows</TargetFramework>   <!-- το .NET 8 και το .NET 9 λήγουν στις 10/11/2026 -->
    <UseWPF>true</UseWPF>
    <ApplicationIcon>app.ico</ApplicationIcon>            <!-- βάλε το app.ico στον φάκελο του έργου -->
    <Version>1.0.0</Version>                              <!-- στο GitHub Actions αντικαθίσταται από το tag -->
    <Product>UOI Study Hub</Product>
    <AssemblyTitle>UOI Study Hub</AssemblyTitle>
    <Description>Εφαρμογή στατιστικών, προγράμματος και μελέτης για φοιτητές ΤΜΗΥΠ ΠΙ</Description>
    <SatelliteResourceLanguages>en</SatelliteResourceLanguages>   <!-- μικρότερο μέγεθος (χωρίς περιττούς φακέλους γλωσσών) -->

2) Τα αρχεία schedule.html, focus.html και notes.html πρέπει να αντιγράφονται δίπλα στο .exe.
   Αν στο Visual Studio έχεις βάλει σε αυτά "Copy to Output Directory = Copy if newer", είναι ήδη εντάξει.
   Στο .csproj πρέπει να φαίνονται έτσι:

    <ItemGroup>
      <Content Include="schedule.html"><CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory></Content>
      <Content Include="focus.html"><CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory></Content>
      <Content Include="notes.html"><CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory></Content>
    </ItemGroup>

3) Δοκιμή του build στον δικό σου υπολογιστή (ίδια εντολή με το GitHub Actions), στον φάκελο του έργου:

    dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish

   Μετά άνοιξε τον φάκελο "publish" και τρέξε το .exe από εκεί.
