# UOI Study Hub 🎓

Desktop εφαρμογή για φοιτητές του Τμήματος Μηχανικών Η/Υ & Πληροφορικής του Πανεπιστημίου Ιωαννίνων: στατιστικά βαθμών, πρόγραμμα, εργαλεία μελέτης και ένα μικρό RPG πάνω από τη φοίτησή σου.

> ⚠️ **Ανεπίσημη εφαρμογή.** Δεν σχετίζεται με το Πανεπιστήμιο Ιωαννίνων. Δες την ενότητα [Αποποίηση ευθύνης](#αποποίηση-ευθύνης).

## Τι κάνει

- **Base Camp:** προφίλ RPG (XP, επίπεδα), επιτεύγματα, Hall of Fame, εξαγωγή README για το GitHub σου.
- **Analytics Engine και 3D Space & Timeline:** γραφήματα βαθμών, εκτίμηση αποφοίτησης, skill tree.
- **Simulator:** σχεδίασε την επόμενη περίοδο και δες πώς αλλάζει ο μέσος όρος σου.
- **Schedule:** το πρόγραμμα μαθημάτων, εργαστηρίων και εξεταστικής διαβάζεται απευθείας από το site του Τμήματος και εμφανίζεται ως γραφικό πλέγμα. Εξαγωγή σε ημερολόγιο (`.ics`) για Google Calendar και Outlook.
- **Study Hub:** Focus Core (Pomodoro) με Zen Mode και καταγραφή μελέτης ανά μάθημα, σημειώσεις ανά μάθημα και Cyber-Radio.
- **Co-op:** σύγκριση με φίλο μέσω αρχείου CSV.
- **Control Center:** Time Machine, θέματα, αυτόματη αποθήκευση προόδου, πλήρης οθόνη (F11).

## Λήψη και εκτέλεση

1. Πήγαινε στη σελίδα **[Releases](https://github.com/OWNER/REPO/releases/latest)** και κατέβασε το αρχείο `UOI-Study-Hub-vX.Y.Z-win-x64.zip`.
2. Δεξί κλικ στο zip και **Εξαγωγή όλων** (μην το τρέξεις μέσα από το zip).
3. Άνοιξε τον φάκελο και κάνε διπλό κλικ στο **Poreia_pros_to_Ptyxio.exe**. Κράτα μέσα στον φάκελο και τα αρχεία `.html` που υπάρχουν δίπλα του.

Δεν χρειάζεται να εγκαταστήσεις τίποτα άλλο (ούτε .NET ούτε προγραμματιστικά εργαλεία). Απαιτούνται **Windows 10 ή 11, 64-bit** και internet για τον συγχρονισμό.

### Η οθόνη «Τα Windows προστάτευσαν τον υπολογιστή σου»

Η εφαρμογή δεν είναι ψηφιακά υπογεγραμμένη (η υπογραφή κοστίζει), οπότε τα Windows (SmartScreen) μπορεί να εμφανίσουν προειδοποίηση την πρώτη φορά. Αν εμπιστεύεσαι την πηγή: **Περισσότερες πληροφορίες** (More info), και μετά **Εκτέλεση ούτως ή άλλως** (Run anyway). Μπορείς να ελέγξεις ότι το αρχείο είναι το αυθεντικό συγκρίνοντας το SHA256 με το `SHA256SUMS.txt` της έκδοσης.

### Συχνές ερωτήσεις

- **Η πρώτη εκκίνηση αργεί λίγο.** Φυσιολογικό: η εφαρμογή αποσυμπιέζει τα εσωτερικά της αρχεία στον προσωρινό φάκελο.
- **Μήνυμα για το «WebView2 Runtime».** Υπάρχει ήδη στα Windows 11 και στα περισσότερα Windows 10. Αν λείπει, η εφαρμογή σε στέλνει στη δωρεάν λήψη από τη Microsoft.
- **Πώς ενημερώνομαι;** Όταν βγει νέα έκδοση, εμφανίζεται 🆕 στη μπάρα αριστερά. Κατέβασε το νέο zip και αντικατάστησε τον παλιό φάκελο. **Τα δεδομένα σου δεν χάνονται**, γιατί αποθηκεύονται ξεχωριστά (`%LocalAppData%\UoiStudyHub`).

## Ιδιωτικότητα και ασφάλεια

- Ο **κωδικός** σου αποθηκεύεται **μόνο αν το επιλέξεις** («Να θυμάμαι»), κρυπτογραφημένος με την προστασία δεδομένων των Windows (DPAPI), δεμένος με τον λογαριασμό σου στον υπολογιστή. Στέλνεται μόνο στο `sso.uoi.gr` για να συνδεθείς.
- Οι **βαθμοί, οι σημειώσεις και η πρόοδός σου** μένουν στον υπολογιστή σου, στο `%LocalAppData%\UoiStudyHub`. Δεν στέλνονται πουθενά. Δεν υπάρχει telemetry ή analytics.
- Η εφαρμογή επικοινωνεί με: `sso.uoi.gr` και `classweb.uoi.gr` (σύνδεση και βαθμοί), `cse.uoi.gr` (πρόγραμμα), `api.github.com` (έλεγχος νέας έκδοσης), Google Fonts, YouTube (Cyber-Radio) και ένα CDN για τις βιβλιοθήκες γραφημάτων.
- Για να σβήσεις τα πάντα: **Αποσύνδεση** μέσα στην εφαρμογή (με όλες τις επιλογές) και διαγραφή του φακέλου `%LocalAppData%\UoiStudyHub`.

## Αποποίηση ευθύνης

Η εφαρμογή **συνδέεται στο ClassWeb με τα δικά σου στοιχεία** και διαβάζει τους βαθμούς σου, όπως θα έκανες εσύ από τον browser. Είναι ανεπίσημη, παρέχεται «ως έχει», μπορεί να σταματήσει να δουλεύει αν αλλάξει το ClassWeb ή το site του Τμήματος, και η χρήση γίνεται με δική σου ευθύνη. Έλεγξε τους κανονισμούς χρήσης των συστημάτων του Πανεπιστημίου. Οι πληροφορίες και οι προβλέψεις της εφαρμογής είναι ενδεικτικές και δεν αντικαθιστούν επίσημη ενημέρωση από τη Γραμματεία.

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish
```
